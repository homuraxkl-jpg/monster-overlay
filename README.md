## 普通玩家修改离线台词

打开游戏目录中的 `nativePC/plugins/CSharp/WhaleCompanion/玩家自定义`：

1. 用记事本打开 **随从台词.txt**，只修改标题下面的中文，保留标题和〔名字〕、〔音符〕标记。
2. 保存文件，退出怪物猎人世界。
3. 双击 **应用修改.cmd**，看到“应用成功”后重新启动游戏。
4. 想回到随包默认内容时，退出游戏后双击 **恢复默认台词.cmd**。

无需编辑JSON、安装Python、输入命令或提供API密钥。文本写错会停止应用，并显示出错位置。默认内容已备好，不修改也可以直接使用。

**离线人设.txt**为可选制作入口：修改它不会自动重写现有台词；需要AI改写时在F9离线编辑器重新加载、生成预览并保存，这一步会使用用户配置的模型和密钥。普通手写、应用文件与游戏运行不调用AI。原生GMD有缓存，离线台词目前需要退出应用并重启，尚不支持热更新。

详细说明见[玩家自定义说明](PLAYER-DIALOGUE-README.md)。当前面向chT主随从自动台词资源，可能影响共用文本的其他随从；实时聊天、记忆、模型与外观独立保留。

## 安装与验收

1. 关闭游戏。按 https://fexty12573.github.io/SharpPluginLoader/Install/Installation.html 安装与 SharpPluginLoader.Core 2.0.0 匹配的加载器。不能仅复制 Core.dll；也不要用 NuGet 文件替代加载器发行包。
2. 游戏根目录已定位到 D:\steam\steamapps\common\Monster Hunter World。原有 dinput8.dll、loader.dll、Lua 与 nativePC 需保留，先确认其兼容性。
3. 将 dist\WhaleCompanion 文件夹复制到游戏 nativePC\plugins\CSharp\ 下。不要把框架依赖重复复制进插件目录。
4. 启动游戏，进入存档后按 F9，在 Whale Companion P0 面板确认中文显示，勾选 Enable read-only probe。
5. 检查生命值和武器类型；使用不同招式确认动作编号变化。受伤与喝药后检查生命值变化，掉血仅标记为 HP decreased，不断言攻击来源。
6. 关闭探针、切换地图或回营后重新开启，确认没有沿用旧血量基线。再检查任务进入／离开事件。重进存档重复检查。
7. 如崩溃，关闭游戏后移除该插件 DLL，并保留加载器日志。托管异常捕获无法保证阻止原生访问异常。

实现使用 SPL 的 Player.MainPlayer、Health、MaxHealth、CurrentWeaponType 和 OnPlayerAction；生命组件指针检查使用该版本框架相同的 0x7630 偏移。游戏版本兼容性必须实测，未声明已稳定。

P0 不连接 AI，不发送公共聊天，不写游戏状态；玩家动作回调仅观察 ref 参数，不更改动作。中文字体从系统 msyh.ttc 注册，需游戏内验证。

## P1 验收范围（待实现后执行）

P1 是 API 对话闭环，不要求测试见切、登龙或居合。当前 P0.2 还没有 API 输入框或对话功能，现在无需再次进游戏测试。

| 测试 | 操作 | 通过标准 |
| --- | --- | --- |
| API 配置 | 填入服务地址、模型名和密钥，保存并重新打开配置 | 配置生效，密钥遮罩显示，日志不包含密钥 |
| 中文对话 | 在游戏内插件输入框输入“你好，你是谁？”，发送 | 正确输入中文，显示一条中文回复，不发送到公共聊天 |
| 连续对话 | 接着问“我刚才问了什么？” | 回复能利用本次会话上下文 |
| 异步响应 | 等待回复时走动或挥刀 | 游戏继续正常响应，界面不因网络等待卡住；不要求特定招式 |
| 错误处理 | 用无效密钥或错误服务地址发起一次请求，再恢复配置 | 显示可理解的错误，恢复配置后能再次对话，游戏不崩溃 |
| 取消及过期回复 | 发起请求后取消或离开当前会话 | 状态及时恢复，迟到结果不会进入新会话 |

API 测试会产生实际调用；每个场景少量请求即可。完成后由开发侧检查脱敏日志和请求状态，不让用户反复盲测。

### 实验性回避累计回应

开启自动陪伴、动作陪伴和 `Experimental all-weapon action and state responses`，并保持武器诊断开启。

| 武器 | 滚动窗口与门槛 |
| --- | --- |
| 弓、双刀 | 30秒内4次有效回避 |
| 其他武器 | 60秒内4次有效回避 |

夸奖后清空当前批次，没有额外固定CD。单次回避的多段接触只计一次，失败或空地回避不加数；过期记录移出窗口，切换武器或场景清空。对话忙时继续计数，实际显示夸奖后才重计；不预存夸奖前的额外回避到下一批。

接受明确的直接攻击来源及已确认敌对发射者的投射物。动作范围仅通用翻滚、弓滑步、双刀鬼人突进斩与垫步。弓滑步和鬼人垫步共用原生回避窗口；突进斩还可依据实际原生动作无敌标志，不会只看到动作就加数。
